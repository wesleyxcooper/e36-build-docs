# Phase 1: Steering — RHD Clearance

**Phase:** 1  
**System tags:** `[STEERING]`  
**Shop-mandatory:** No  
**Prerequisites:** Interior strip complete (01-interior-prep). Do this before Phase 3 turbo work — the stock RHD rubber coupler will conflict with any top-mount manifold.

## Parts

| Part | PN / Source | Cost |
| --- | --- | --- |
| Condor Speed Shop Slim RHD Steering Shaft | [condorspeedshop.com](https://www.condorspeedshop.com/products/steering-shaft-conversion-e36) | $308.99 |

## Tools

- Standard socket set and ratchet
- Torque wrench
- Protractor or angle finder (verify U-joint angles at install — both must be below ~15°)

## Procedure

1. ✅ **Confirm RHD fitment before ordering.** Manufacturer confirmation: *"All E36's including right-hand drive models."* No modification required for RHD.

2. ✅ **Confirm EPS compatibility.** The EPS motor acts on the column above the firewall; this shaft operates below the firewall to the rack — no interference between the two systems. EPS-equipped cars install this shaft without any modification to the EPS unit.
   - If running a KPower/EPowerSteering column-core EPS system: confirm the column lower output spline size matches the Condor shaft upper U-joint at order time. Spline should be unchanged, but verify before the shaft ships.

3. ✅ Install Condor Speed Shop Slim RHD Steering Shaft ($308.99). Replaces the stock rubber coupler with a chromoly dual U-joint shaft.

4. ✅ After install, verify both U-joint angles are **below ~15°**. Steep angles create torque oscillation that can feed through an EPS controller as noise.
   > ⚠️ **Pitfall:** Mandatory before Phase 3 turbo work — do it now while the engine bay is accessible. The stock RHD rubber coupler will conflict with any top-mount manifold. Do not skip.
