# Air Conditioning — Electric Compressor Wiring & Installation

**Phase:** 3  
**System tags:** `[AC]` `[ELECTRICAL]` `[THERMAL]`  
**Shop-mandatory:** Partial (AC line fabrication and refrigerant charge = shop; all wiring = DIY)  
**Prerequisites:** 07K installed; CWA400 and main power distribution (PMU16) wired; existing E36 condenser and evaporator in place; AC system flushed and receiver/drier replaced; AC lines from M52 era removed or capped

---

## Overview

The OEM M52 AC compressor was belt-driven from the engine. The 07K AC delete kit (TDC Shop) removes the compressor from the serpentine belt path entirely. In its place: the Alibaba `PD2-18012AJA` 12V electric scroll compressor — mounts anywhere in the engine bay, independent of the belt, drawing ~50A from the chassis electrical system.

The compressor ships with a standalone 3-phase inverter/PWM controller. MaxxECU reads the AC switch via DIN, prepares an idle-up, then CAN-commands PMU16 O7 to close the main 100A relay.

**Wiring reference:** `harnesses/ac-compressor.wv`

**Belt path note:** If the HPS pump has been deleted (K2 Industries delete kit from `13-eps.md`), the belt path is already simplified. If HPS pump coexists, confirm the existing belt layout still accommodates the AC compressor pulley location — the OEM AC compressor pulley is removed with the M52 AC compressor. The 12V electric compressor is **not** in the belt path at all and mounts independently.

## Procedure

### Compressor Mounting

1. Select a mounting location in the engine bay away from exhaust heat (avoid driver side near SPA manifold and downpipe). The 12V electric compressor is not in the belt path — mount on the passenger side (intake side) or front of the bay for shortest line runs to the condenser. Use rubber isolator mounts between compressor body and bracket to reduce vibration transmission.
   > ⚠️ **Pitfall:** Mount compressor away from exhaust heat. The PD2-18012AJA is a scroll compressor — it does not tolerate sustained high ambient temperatures from exhaust proximity.

2. Do not energize the compressor without the condenser fan circuit present. **The PWM controller will not activate the compressor without a fan circuit.** Source: `harnesses/ac-compressor.wv` PWM_CONTROLLER notes.

### Serpentine Belt Path Confirmation

3. The OEM belt-driven AC compressor has been removed with the M52. The 12V electric compressor is not in any belt path. **However:** if the TDC Shop 07K AC Delete Kit was also installed (for the 07K belt path), confirm all pulleys in the new layout are accounted for. The TDC kit provides a billet dual-belt alternator pulley; the OEM AC idler is repositioned within the kit. The electric AC compressor adds zero belt load. Source: `E36_9000RPM_Project_Plan_Verified.md` Accessory Belt row.

### AC System Flush & Preparation

4. Before installing the electric compressor: **flush all PAG oil from the AC system** (condenser, evaporator, all lines). The PD2-18012AJA requires **POE 68 oil** — PAG is incompatible. A PAG/POE mixture causes oil breakdown and compressor failure.
   > ⚠️ **Pitfall:** Oil type is critical. Use POE 68 only — NOT PAG. Flush entire AC system (condenser, evaporator, all lines) before install to purge PAG oil; replace receiver/drier any time the system is opened. Source: `harnesses/ac-compressor.wv` COMPRESSOR notes.

5. Replace the receiver/drier — mandatory any time the system has been opened to atmosphere.

6. **AC line fabrication (shop):** The new 12V compressor mounting location requires custom lines from compressor → condenser (high-side) and evaporator → compressor (low-side). Hose sizing: #10 for evaporator → compressor (low-side), #8 for compressor → condenser (high-side). This is a shop job — requires proper AC fittings and leak testing before charge.

### Power Wiring

7. **Battery → relay pin 30 (compressor main power):**
   - Install 100A fuse within 12 inches of the battery terminal
   - Run 8 AWG OFC from battery → relay pin 30
   - Big Three upgrade (0 AWG OFC from battery to engine bay junction post) required alongside AC install for clean power delivery at ~50A draw. Source: `E36_9000RPM_Project_Plan_Verified.md` AC row.

8. **Relay pin 87 → PWM controller +DC_IN:**
   - 8 AWG, ~1.5m run from relay to compressor mounting location
   - Switched +12V supply to PWM controller when relay is energized

9. **PWM controller −DC_IN → chassis GND:**
   - 8 AWG, short stub from controller to nearest chassis GND stud
   - Do not share with signal grounds or other high-current GND runs

10. **Flyback diode on relay coil:**
    - Install 1N4007 across relay coil pins 85/86
    - Cathode (banded end) → pin 86 (+12V coil supply)
    - Anode → pin 85 (coil GND / GPO sink)
    - Prevents GPO output damage from coil back-EMF at de-energization. Source: `harnesses/ac-compressor.wv` AC_RELAY notes.

### PMU16 O7 → Relay Coil (CAN-Commanded)

11. **PMU16 O7 (15A, PHYS pin 10) → relay coil pin 86:**
    - 18 AWG, ~1.5m from PMU16 39-pin connector to relay coil
    - MaxxECU reads AC switch via DIN, sends CAN command to PMU16 → O7 activates → relay energizes → compressor runs
    - This gives MaxxECU control over the compressor: idle-up before relay closes, CLT lockout at high coolant temp

12. **Relay coil pin 85 → chassis GND:**
    - 18 AWG, short stub
    - Source: `harnesses/ac-compressor.wv` connections block

### AC Switch → MaxxECU DIN (Enable Signal)

13. AC switch output now feeds MaxxECU DIN directly — **not** directly to the relay coil:
    - IGN +12V → cabin AC switch input (existing E36 AC switch can be reused)
    - AC switch output → MaxxECU DIN (AC enable signal), 22 AWG shielded, ~2.5m run through firewall grommet to ECU
    - MaxxECU reads AC-on signal, prepares idle-up, then CAN-commands PMU16 O7 to close the relay
    - Source: `harnesses/ac-compressor.wv` AC_SWITCH and MAXXECU_DIN notes

14. **MTune AC enable configuration:**
    - Digital Input → assigned DIN → type: ON/OFF switch → function: AC enable
    - Idle-up when AC enable is HIGH: +150–200 RPM additional idle target
    - Source: `harnesses/ac-compressor.wv` MAXXECU_DIN notes

### 3-Phase Motor Wiring

15. **PWM controller U/V/W → compressor motor:**
    - 3× 8 AWG minimum (or match factory kit harness gauge)
    - Short run — mount inverter adjacent to compressor
    - Phase order: follow controller labeling. **Swapping any two phases reverses motor rotation** — compressor will not compress. Source: `harnesses/ac-compressor.wv` COMPRESSOR notes.

### Commissioning

16. **Do not start at 100% duty.** PWM controller duty cycle knob:
    - Start at **~45% duty ≈ 3,000 RPM** — good cooling (~51–54°F vent at 90°F ambient) with manageable idle behavior
    - Do NOT start at 95% (5,000 RPM) — causes near-stall idle dip. Source: `harnesses/ac-compressor.wv` PWM_CONTROLLER notes.
    > ⚠️ **Pitfall:** Start at ~45% duty cycle (3,000 RPM). Do not start at 95% — near-stall idle dip. Tune duty cycle upward gradually in 5% increments while monitoring idle stability. Source: `harnesses/ac-compressor.wv` TODO list.

17. Shop: refrigerant charge with R134a after all line fabrication and compressor mounting is complete. Confirm condenser fan is operational before charging — controller will not activate compressor without fan circuit.

18. Test with engine running: monitor idle via MTune, verify idle-up when AC switch is on (+150–200 RPM), adjust duty cycle in 5% increments for cooling performance vs idle stability.
