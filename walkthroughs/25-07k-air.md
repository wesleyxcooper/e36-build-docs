## Procedure

### 1 — LPS phenolic intake gasket

Install the **LPS 07K Phenolic Intake Gasket** (1/8" thick phenolic, [lpsfab.com](https://lpsfab.com/products/lps-07k-phenolic-intake-gasket)) between the cylinder head and the intake manifold. This heat isolator limits IAT heat soak from the hot aluminum head into the charge. Install **before** manifold bolts go in — it cannot be added after.

Compatible with both BBG and LPS longitudinal manifolds.

### 2 — BBG longitudinal intake manifold

Install the **BBG Longitudinal Intake Manifold** ($971.00, [boostbrothersgarage.com](https://www.boostbrothersgarage.com/products/07k-swap-intake-manifold)) on the intake side of the engine.

Torque manifold fasteners to spec. Route vacuum/boost reference hose from a post-throttle-body port on the manifold to the MAP sensor.

### 3 — Throttle body path decision (decide before building the harness)

**This decision must be locked before starting `26-07k-harness.md`.** The harness build is different for DBW vs cable.

---

**Option A — DBW (stock 07K TB, MaxxECU e-throttle) — recommended path:**

Retain the factory 07K DBW throttle body (~65 mm bore — adequate for ~500 whp at 25 psi). Wire it via the 07K engine harness (see `26-07k-harness.md` — ME7.1.1 pins: Motor+ = **84**, Motor− = **92**, TPS1 = **117**, TPS2 = **118**).

DBW enables throttle blip on downshift, traction control throttle management, launch control, and flat shift — all MaxxECU features unavailable with cable.

**DBW throttle body sizing note:** The stock 07K TB is ~65 mm — sufficient to ~500 whp at 25 psi per Rennlist 07K community airflow calculations. For 600–750+ whp targets, plan to upgrade to VW 3.6 VR6 TB `03H133062` (~74 mm, same VAG flange, direct fit candidate on BBG manifold, ~$40–80 used). Do not upgrade before the tune is dialed in.

**Accelerator pedal (DBW path):** Install the BMW E46 accelerator pedal module (`35426786282`, ~$80–120 used from eBay) via the Strom Motorsports E36 → E46 adapter bracket. The E46 pedal is a dual-track (APS1 + APS2) 6-wire module.

APS wiring is **cabin-to-cabin** — the pedal is footwell-mounted and MaxxECU is cabin-mounted. The 6 wires run from the pedal to the **Maven HD30 Connector A cabin face (pins A14–A19)**, which acts as a junction block. No signal crosses to the engine side. AS79 pins are not used for APS.

- ME7.1.1 connector reference (for OEM harness mapping — see `26-07k-harness.md`):
  - APS 1 signal: **pin 35** / APS 1 GND: **pin 72**
  - APS 2 signal: **pin 34** / APS 2 GND: **pin 73**

Source: `harnesses/epedal-bmw-e46.wv`, `harnesses/firewall-bulkhead-dual.wv`.

> ⚠️ **RHD bracket fitment note:** No vendor explicitly confirms RHD E36 pedal box compatibility for the Strom/Garagistic bracket. LHD brackets often misalign in RHD — typically resolved by trimming carpet/sound deadening at the transmission tunnel edge. If RHD pedal box geometry prevents fitment, substitute the Hella `6PV010946-141` standalone floor-mount module (no OEM pedal box geometry dependency, ~$80–120 new; MaxxECU has a native pre-defined profile for it).

The DBW throttle body wiring is part of the **07K engine harness build** (`26-07k-harness.md`). The e-pedal wiring runs separately as a cabin cable from the pedal to the HD30 Connector A cabin face (pins A14–A19 cavity-plugged at Phase 3 bulkhead install).

> ⚠️ **Pitfall:** Disconnect the TB motor wires before enabling e-throttle in MTune for the first time. Leave sensor wires connected — verify APS/TPS voltages read correctly before activating motor drive. This prevents a runaway condition on first output enable.

---

**Option B — Cable throttle (VR6 OBD2 TB + Lokar cable):**

Install VR6 OBD2 TB `021133064A` on the BBG manifold (OBD2 96–99 only; bolt pattern matches). Install Lokar LOK-TC-1000LS148 throttle cable (cut to fit; adjust drum end for VR6 TB).

**The stock E36 cable cannot be reused** — the VR6 TB drum uses a different cable end than the M52 drum. The stock E36 floor pedal is retained (no E46 pedal module needed).

MaxxECU still receives TPS signal passively for datalog and boost control. No e-throttle calibration needed. No throttle blip, traction control throttle management, launch control, or flat shift available with cable.

Include TPS1/TPS2 signal wires in the 07K harness build regardless of this choice (for MaxxECU throttle position reading). No TB motor wiring needed for cable path.

---

### 4 — TMAP sensor (MAP)

Install a 3-bar MAP sensor (GM `12592525` or equivalent) at the BBG manifold's MAP port. The 3-bar sensor is required for boosted applications — the stock 1-bar unit cannot read boost above atmosphere.

Route the vacuum/boost reference line from the manifold post-throttle-body port to the sensor.

**ME7.1.1 OEM reference:** MAP sensor at **pin 101** in the ME7.1.1 engine connector. Wiring to MaxxECU is covered in `26-07k-harness.md`.

> ⚠️ **Note:** The DBW TB wiring and APS pedal wiring are part of the **07K harness build** (`26-07k-harness.md`), not the intake system installation. Complete the air system first (manifold, TB, MAP) then build the harness.
